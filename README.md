# Penny

**A simple, private expense tracker for Android.**

Track your spending, manage your monthly budget, and keep tabs on money you owe or are owed, without a cluttered interface.

[**Download the latest APK**](https://github.com/abhim5yu/Penny-releases/releases/latest)

---

## Features

- **Expense tracking** — record and review transactions.
- **Monthly budget** — set a spending limit and keep expenses in view.
- **Opening balance** — start with your current balance.
- **Loans** — keep track of money lent and borrowed.
- **Simple interface** — focused tools without unnecessary clutter.

## Install

1. Open the [Latest Release](https://github.com/abhim5yu/Penny-releases/releases/latest).
2. Under **Assets**, download the APK file.
3. Open the downloaded file and follow Android's installation prompts.

If Android asks for permission to install apps from your browser, allow it only for the browser you used to download the APK. If an update cannot install, it may be signed with a different key. **Back up your data before updating.**

## Updates

New builds are published on the [Releases page](https://github.com/abhim5yu/Penny-releases/releases). Check the release notes for changes and fixes.

## Privacy

Penny is intended for personal expense tracking. Review the app's permissions and source code before storing sensitive financial records. Keep your own backup of important data.
